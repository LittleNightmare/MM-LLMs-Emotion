# 训练方案（SFT 与 RL）

2026-10-27 起草，同日修订：并入三缺口文献先例（第 8 节），按 experiment-plan 口径补齐主张、冻结评价面与运行清单。本文件是计划与 tracker，不是执行记录；**尚未授权执行，未启动任何实验**。

目标：把「原始模型 → SFT → RL」三阶段放在同一基座、同一划分、同一推理设置下比较，指标按课程要求给出情感 Macro-F1、冲突识别准确率和过度判断率。

## 0. 主张与证伪条件

| # | 主张 | 证伪 / 反例观察 | 最低可信证据 |
| --- | --- | --- | --- |
| C1 | 自设计规则奖励的 RL 在冻结评价面上降低过度判断率（证据不足子集上无保留判断的比例）并控制不必要追问，同时情感 Macro-F1、冲突 F1 不低于原始基线（容忍线：Macro-F1 降幅 ≤ 2 个百分点） | uncertain_rate 大涨、清晰子集确定判断正确率下降、情感 F1 跌破容忍线 ⇒ 改善只来自「整体变保守」，C1 不成立 | 三阶段同评价面配对对比（B1）＋奖励消融（B2） |
| C2 | SFT 提供格式与情感主体增益；RL 的增量集中在不确定行为与冲突判别 | RL 相对 SFT 各维度差异均在噪声内 ⇒ 对 C2 是有效负结果（「RL 无增量」），不推翻 C1 但收窄结论 | 子集分解：清晰子集判断质量 vs 证据不足子集弃答质量分列（参照 TAPS 的 answering/distinguishing 分解思想） |

实验块：B1 三阶段主对比（必做）；B2 奖励消融（必做）；B3 人工评价＋典型案例/Demo（必做，课程硬要求）；B4 连续校准指标 ECE/Brier（选做，附录级）；不设 simplicity / frontier 检查块——课程作业不主张方法学新颖性，LLM 后训练是课程设定本身。

| 项 | 取值 |
| --- | --- |
| 基座 | `Qwen2.5-Omni-3B`（Thinker 部分），零样本结果见[基线实验](基线实验.md) |

三阶段只允许「训练与否」这一个变量变化。提示词、帧数、解码参数、评测脚本都冻结，改动就重跑全部三阶段。

评价面冻结（先于任何训练固定，候选训练不得重定义标签、评价器、分母或成功阈值）：

- 自动指标沿用 `baseline.py` 口径：`emotion_macro_f1_present`（验证集实际出现的两类）、冲突 Precision/Recall/F1、JSON 合格率、`uncertain_rate`；非法或不可解析输出计入分母按错计。
- 新增指标（公式见第 4 节，实现后先单测再训练）：过度判断率、清晰子集确定判断正确率、不必要追问率；分母为零一律记「不可计算」，不写 0。
- 人工评价子集与训练补标按 `split_group_id` 同源隔离；这是责任边界，当前没有物理隔离。
- 选型与早停只用训练侧信号和 val 官方标签；人工评价标签只评不训，不用于奖励调参。
- 基线复用：`results/small-baselines-20261021/` 的 Omni-3B（VA）结果，推理设置与本表一致才可复用；不一致则重跑基线。

## 2. SFT 数据构造

从训练集 3354 条出发，按目标输出拼样本。每类样本都要能追溯到原始 `sample_id`，便于复核与去重。

| 样本类型 | 来源 | 目标输出 |
| --- | --- | --- |
| 情感判断 | `views.M12.label` | `pred_emotion` 与标签一致，`is_conflict` 按 `sample_type`，`is_uncertain=no`，`clarifying_question=none` |
| 模态冲突 | `sample_type=Conflict`（411 条） | `is_conflict=yes`；情感仍取 M12，避免把「冲突」等同于「不可判」 |
| 证据不足 | 补标裁定（主）＋合成（辅） | `is_uncertain=yes` ＋ 一个具体追问，标注区分「证据不足 / 线索冲突但可消解」子类 |
| 追问与更新（合成） | 见第 4 节 | 问题 → 用户回答 → 修订后的判断 |

要点：

- **不把 Conflict 直接当不确定**。冲突可以消解，是否追问要单独造监督，否则模型会学成「见冲突就拒答」。
- **不确定样本以补标裁定为主来源**：训练集抽样由 ≥3 人按规范独立标「证据充分性」，多数不足阈值 → `is_uncertain=yes`，记录裁定理由，并保留全部标注者的原始记录（不只存聚合结果）。合成样本（截断、加噪、静音画面）仅作补充，来源单独标记。
- 补标前先做小批校准轮讨论边界案例，指南版本化；一致性目标 Fleiss' κ ≥ 0.2（自发情感标注的现实锚点 0.2–0.35，见第 8 节 DementiaBank-Emotion、EmoNet-Face；设定更高阈值只会逼出假共识）。
- 合成样本只进训练集，与评价集按 `split_group_id` 隔离；同一视频的衍生样本归到同一边。
- 追问的参考答案允许多种措辞，训练目标是「问出缺失的那一类信息」，不是背句子。

## 3. RL 奖励

用可验证的部分做规则奖励，主观部分留给人工评测，不把模型自评当奖励来源。

| 维度 | 权重 | 判据 |
| --- | ---: | --- |
| 情感正确 | 0.5 | `pred_emotion` 与 M12 一致得 1，否则 0 |
| 冲突识别 | 0.3 | 真冲突判 `yes`、真一致判 `no` 各算对；只判一半按比例给分 |
| 格式合法 | 0.1 | 能解析出完整 JSON 且字段取值合法 |
| 过度追问惩罚 | 0.1 | 人工裁定无需澄清的训练样本上输出 `is_uncertain=yes` 或非 `none` 追问则扣分（判据来自补标，不用 `sample_type` 代替） |

追问质量不进入自动奖励：措辞多样、无法用字符串匹配判定。它在人工评测里单独打分，避免奖励作弊（例如一律输出同一句「能再说说吗」）。

设计警示（文献教训，见第 8 节）：

- 弃答/不确定行为直接进 RL 奖励会带来两个已记录的失败模式：answer-rate collapse（TAPS：abstention 类 RL 训练后作答率塌缩进窄区间，奖励扫档也拉不开）与过自信配置敏感（EmoCaliber：Brier 奖励＋标准 GRPO 使置信度全堆 >0.9，须改 log-likelihood 形式并去掉 advantage normalization）。因此本方案奖励只含可验证项，不确定行为质量由第 4 节人工评价度量。
- 若需要「不确定行为进奖励」的变体（课程答辩可展示）：采用 TruthRL 式 +1/0/−1（正确/弃答/错误）或 EmoCaliber Eq.4 的 log-likelihood 置信度奖励，并在训练中监控 `uncertain_rate` 轨迹防塌缩——列为可选消融 R010。
- 不奖励问题数量本身（CLARITI：问题数增多时可回答比例反降；候选问题全不达标时最优行为是沉默）。

## 4. 不确定行为指标与多轮更新

**过度判断率**（拟议口径，非官方定义）：

```
过度判断率 = 该类样本中 is_uncertain=no 且给出明确情感的条数 / 该类已裁定样本数
```

分母取人工判为「证据不足、尚不能可靠确定情感」的已裁定样本数；分子按完整回答及行为裁定。分母为零记「不可计算」，不写 0。

**三列同报**（防「总说不确定」刷分；单一比率会被作答率污染，这是 TAPS 的 coverage/risk 分报原则）：

1. 过度判断率（上式）；
2. `uncertain_rate`（全验证集表达不确定的比例）；
3. 清晰子集确定判断正确率（人工裁定「清晰可判断」子集上，模型确定判断中正确的比例；对标 risk＝作答集合内错误率的对偶）。

配套：**不必要追问率** ＝ 人工裁定「无需追问」样本中追问 ≠ `none` 的比例。与过度判断率构成双向口径（漏报不确定由过度判断率捕捉，滥问由本指标捕捉；对标 ClarQ-LLM 的 AQD 双向思想）。

行为裁定细则：`is_uncertain=yes` 却给 `none` 追问，计格式错误而不是不计入；结构化字段与其余回答矛盾时按完整行为裁定；「不追问直接猜」可计过度判断而不论结果对错（ClarQ-LLM §I 对 seeker 猜答案即使猜对也判失败的口径）。

**多轮更新**：从验证集挑 20–30 条冲突或低置信样本，人工写「问题—回答—修订后判断」，覆盖三种结果：改判、保持原判、仍不确定。用户回答可来自人工编写或模拟，来源在文档里标注，不冒充真实用户。案例结构可参照 ClarQ-LLM 的「问题—回答树」：同一缺失信息允许多种问法与顺序，回答允许分叉，不要求固定脚本。

## 5. 评测协议

三阶段各跑一次完整验证集（666 条），同一脚本、同一缓存媒体：

1. 情感 Macro-F1：验证集只有正向、负向，报两类宏平均，同时报三分类固定口径便于对照。
2. 冲突识别：准确率之外必须报 Precision / Recall / F1（74 条正例，单看准确率会被 88.9% 的全「无冲突」基线骗过）。
3. 过度判断率：在人工评价子集上算，与 `uncertain_rate`、清晰子集确定判断正确率三列同报（第 4 节），不互相替代。
4. 追问质量：抽样不少于 50 条，三档「可用 / 空泛 / 误导」；判定维度按 redundant（答案已在输入里或不必要）/ answerable（用户答得出）/ relevant（问到能区分候选判断的缺口）三分组织，允许多种措辞，不做字符串完全匹配（ClarQ-LLM 显式弃用 BLEU 类表面匹配；三分法来自 CLARITI）。可另做成对比较（GSB 式）作为低成本复核。
5. 附录级（选做）：verbalized 置信度的 ECE（10 bins）与 Brier（JAFC / EmoCaliber 协议），作为连续校准辅助证据；实现成本高则裁掉。

统计口径：三阶段同一验证集配对比较；SFT 3 个种子报均值±范围；RL 单种子（预算限制，明示不确定性未量化）；人工评价双标注报 κ；全部 attempts（含失败、超时）保留在各自输出目录，缺的指标保持缺失，不以 0 充当。

## 7. 风险与未决

- **风险**：人工「证据不足」子集 κ < 0.2 或子集过小 → 过度判断率不可靠。缓解：校准轮＋分层抽样每格 ≥10 条；仍失败则该指标标 inconclusive，退化为 `uncertain_rate` ＋清晰子集正确率两列报告。
- **风险**：GRPO 与 Transformers 5.20.2 / trl 的兼容性未核实。缓解：R002 先行冒烟；失败则退 RLOO 或 REINFORCE 式实现，奖励函数设计保留（满足课程「自设计奖励函数」要求）。
- **风险**：本机 8GB 与平台结果不可互证。缓解：正式数字只出自平台，本机只做 sanity。
- 未决：过度判断率的课程 / Kaggle 官方口径（文献只提供方法学先例，不替代官方定义）；LoRA rank/alpha 与目标模块（先 r=16 全线性层，训不动再调）；合成「证据不足」样本具体做法（先看 10 条样例再定）；R010 是否执行（答辩展示需要与否）。

## 8. 文献锚点（2026-10-27 检索）

完整检索报告见当日会话记录；此处只列被本方案引用的先例与其用途。标注为 preprint 的条目未见正式发表版本。

- [TAPS](https://arxiv.org/abs/2610.16318)（arXiv 2610.16318，preprint）：coverage/risk 分报与 matched coverage 原则（第 4 节三列同报）；answer-rate collapse 警示（第 3 节）。
- [ClarQ-LLM / ClarQ4LLM](https://arxiv.org/abs/2409.06097)（IEEE TASLP 2026）：不问就猜判失败的行为口径；AQD 双向差额；弃用 BLEU 类表面匹配；问题—回答树（第 4、5 节）。
- [Just Ask for Calibration](https://arxiv.org/abs/2305.14975)（EMNLP 2023）：ECE/Brier/AUC 连续校准指标（第 5 节附录级）。
- [EmoCaliber](https://arxiv.org/abs/2512.15528)（Pattern Recognition 2026 专刊；正文按 arXiv 预印本）：情感域置信度口头化＋RL 校准；Brier 奖励＋标准 GRPO 过自信教训与 log-likelihood 奖励形式（第 3 节）。
- [DementiaBank-Emotion](https://arxiv.org/abs/2602.04247)（HeaLING Workshop @ EACL 2026）：裁定失败→显式 ambiguous；歧义二分（线索不足 vs 线索兼容多类）；校准工作坊使 Fleiss' κ 0.094→0.313；κ 现实锚点（第 2 节）。
- [EmoNet-Face](https://arxiv.org/abs/2505.20033)（arXiv，preprint）：保留 per-annotator 原始评分、连续分布承载歧义（第 2 节）。
- [MER 2024](https://arxiv.org/abs/2404.17113)（arXiv，preprint）：多数投票丢信息的上游机制证据（课程数据缺不确定性标签的可能成因），ACC/WAF 口径参照。
- [CLARITI](https://arxiv.org/abs/2604.14624)（ICML 2026）：四阶段追问奖励蓝图；redundant/answerable/relevant 三分法；不奖励问题数（第 3、5 节）。
