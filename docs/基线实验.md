# 基线实验

2026-10-21。使用官方模型进行零样本测试，尚未进行本任务的 SFT 或 RL。

## 1. 数据格式

数据位于 `Dataset/`，JSONL 每行一条样本。VT 是画面加文字，不输入音轨；VA 是画面加音频，不额外输入文字稿。同一视频可以对应两种协议。

| 文件 | 样本数 | VT | VA |
| --- | ---: | ---: | ---: |
| `train.jsonl` | 3354 | 1780 | 1574 |
| `val.jsonl` | 666 | 345 | 321 |
| `test_release.jsonl` | 734 | 385 | 349 |

训练、验证数据的主要字段如下：

```json
{
  "sample_id": "ch_sims_v2:VT:video_0001:0001",
  "protocol": "VT",
  "video": "videos/video_0001/0001.mp4",
  "text_content": "我不想嫁给李茶",
  "sample_type": "Aligned",
  "views": {
    "M1": {"label": "negative"},
    "M2": {"label": "negative"},
    "M12": {"label": "negative"}
  }
}
```

`video` 是相对于数据目录的路径。M1 为画面标签，M2 为文字或音频标签，M12 为综合情感标签。情感分为 `negative / positive / neutral`，`sample_type` 分为一致（Aligned）和冲突（Conflict）。

测试集只有 `sample_id`、`video`、`text`，协议根据 ID 和视频目录区分。提交文件包含 `sample_id,pred_emotion,is_uncertain,clarifying_question` 四列。

验证集有 414 条负向、252 条正向、0 条中性，包含 74 条冲突样本。数据没有独立的不确定性标签和标准追问。

## 2. 测试模型

以下均为官方指令／后训练版本，“基模”表示尚未经过本任务训练。统一使用 BF16，不量化。

| 模型 | 输入能力 | 实际加载参数 | 测试范围 |
| --- | --- | ---: | --- |
| [Gemma 4 E2B IT](https://huggingface.co/google/gemma-4-E2B-it) | 文字、画面、音频 | 未记录 | VT + VA |
| [Qwen2.5-Omni-7B](https://huggingface.co/Qwen/Qwen2.5-Omni-7B) | 文字、画面、音频 | 未记录 | VT + VA |
| [Qwen2.5-Omni-3B](https://huggingface.co/Qwen/Qwen2.5-Omni-3B) | 文字、画面、音频 | 4.703B | VT + VA |
| [Qwen3.5-0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B) | 文字、画面 | 0.853B | 仅 VT |
| [Qwen3.5-2B](https://huggingface.co/Qwen/Qwen3.5-2B) | 文字、画面 | 2.213B | 仅 VT |

加载参数包含模态编码器。Omni 仅加载负责理解和文字输出的 Thinker；Gemma E2B 的有效参数约 2.3B，含嵌入约 5.1B。

## 3. 实验方式

使用完整验证集；Qwen3.5 不支持原生音频，只测试其中的 VT 样本。模型输入不包含标签。

| 项目 | 设置 |
| --- | --- |
| 硬件 | 单张 RTX 4090，48GB 显存 |
| 环境 | Python 3.12、PyTorch 2.13.0+cu132、Transformers 5.20.2 |
| 视频 | 全片均匀采样 8 帧，最长边 448 像素 |
| 音频 | 完整音轨，16kHz 单声道 |
| 生成 | 单条推理、贪心解码、最多 192 token、随机种子 42 |
| 提示词 | 相同中文任务说明，使用各模型原生模板；Qwen3.5 关闭思考模式 |

模型输出：

```json
{"pred_emotion":"negative","is_conflict":"no","is_uncertain":"no","clarifying_question":"none"}
```

情感准确率按解析出的标签计算，无法解析或非法标签计错；JSON 合格率另行统计。Macro-F1 取验证集中出现的正向、负向两类，冲突 F1 以冲突为正类。不确定性和追问没有标准答案，未评分。

## 4. 测试结果

以下为本地验证结果，未向 Kaggle 提交。“—”表示未测试。

| 模型 | 全量准确率（666） | VT 准确率（345） | VA 准确率（321） | 推理显存峰值（GiB） |
| --- | ---: | ---: | ---: | ---: |
| Gemma 4 E2B IT | 59.46% | 68.70% | 49.53% | 9.68 |
| Qwen2.5-Omni-7B | 70.27% | 68.99% | 71.65% | 17.05 |
| Qwen2.5-Omni-3B | 67.87% | 70.72% | 64.80% | 9.14 |
| Qwen3.5-0.8B | — | 46.09% | — | 1.72 |
| Qwen3.5-2B | — | 84.64% | — | 4.26 |

显存为 PyTorch 已分配显存峰值，不代表训练显存或显卡容量下限。

| 模型 | 统计范围 | Macro-F1 | 冲突准确率 | 冲突 F1 | JSON 合格率 |
| --- | --- | ---: | ---: | ---: | ---: |
| Gemma 4 E2B IT | 全量 | 0.7157 | 78.98% | 0.0519 | 81.38% |
| Qwen2.5-Omni-7B | 全量 | 0.7930 | 86.79% | 0.0000 | 96.10% |
| Qwen2.5-Omni-3B | 全量 | 0.7778 | 88.74% | 0.0000 | 100.00% |
| Qwen3.5-0.8B | 仅 VT | 0.5430 | 3.48% | 0.0543 | 33.62% |
| Qwen3.5-2B | 仅 VT | 0.8461 | 74.78% | 0.0440 | 100.00% |

全量与 VT 指标的样本范围不同，应分开比较。全量全部预测负向的准确率为 62.16%，全部预测无冲突为 88.89%。

五组测试均无运行错误。0.8B 存在较多 JSON 格式错误，345 条中有 169 条无法解析情感；Omni-3B 未检出 74 条冲突中的任何一条，2B 检出 VT 中 64 条冲突中的 2 条。

另将 VT 固定交给 Qwen3.5-2B、VA 固定交给 Omni-3B，复用已有预测，组合准确率为 **75.08%**、Macro-F1 为 **0.8120**。这是查看验证结果后做的离线组合，未做独立测试，也未实测组合部署。

## 5. 平台复现（A100，2026-10-27）

在 Intern Discovery 的 A100-80G 上用同一个脚本复现 Omni-3B 零样本，环境是 Python 3.12 + torch 2.7.1+cu126（自定义镜像），四路分片并行跑完 666 条。

| 指标 | 平台 A100 | 本地 4090 |
| --- | ---: | ---: |
| 全量准确率 | **68.92%** | 67.87% |
| Macro-F1（正向/负向） | **0.7859** | 0.7778 |
| 冲突 F1 | 0.0000 | 0.0000 |
| JSON 合格率 | 100% | 100% |
| 错误 | 0 | 0 |

差异在 1 个百分点内，属于解码环境和样本顺序的波动。两次都**没有检出任何冲突样本**，说明这是模型能力问题而不是实现问题，SFT 的核心目标就是补上这一块。

第一版平台运行有 30 条错误（VA 无音轨 28 条、坏视频 2 条），是 `ensure_audio` 与缓存片段解码的缺陷，已修复后重跑；表中是修复后的结果。

同一天用这份零样本预测提交 Kaggle（ref `57697134`），Public 分数 **0.60403**：冲突项得 0，一致校准拿满，反推情感 Macro-F1 约 0.81。0.3 的冲突分完全没拿到，是后续提升空间的主要来源。
