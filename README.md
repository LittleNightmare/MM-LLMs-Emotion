# 多模态情感识别与大模型后训练

## 1. 任务内容

这次大作业选择的是“大模型后训练”方向。输入一段视频，模型结合画面、声音和文字判断人物的情感，并给出回应。如果信息不足，或者不同信息之间存在矛盾，模型需要表达不确定，向用户提问，再根据用户的回答更新判断。

例如，一个人笑着说“我没事”，但声音有些哽咽。画面、语气和说话内容可能表达不同的情感，这就是模态冲突。模型需要发现这种差异，并通过进一步询问了解情况。

整个实验包括原始模型推理、监督微调和强化学习三个阶段，最后比较三个版本的表现，并完成一个可以交互的 Demo。我们使用已有的开源模型继续训练，不需要从零训练大模型。

目前仓库还没有代码，模型和数据也没有确定。下面按实际工作顺序说明各部分。

## 2. 数据准备

课程要求使用统一提供的多模态情感数据。多模态指的是视频中的画面、音频以及字幕或语音转写等文字信息。

拿到数据后，先查看视频格式、样本数量、情感类别和标注内容，确认是否已经分好训练集、验证集和测试集。训练集用于更新模型，验证集用于调整参数，测试集用于最后比较效果。

除了情感标签，还需要确认有没有“模态冲突”和“证据不足”的标注。这些标注会影响后面的奖励设计和评测。如果数据只有情感类别，需要向老师确认其余部分如何标注和评价。

材料没有给出数据下载地址，也没有明确数据集名称。Emotion-LLaMA、R1-Omni 和 MER 2024 是参考资料，具体使用哪份数据还要等课程说明。

## 3. 模型和环境

需要选择一个能在本地或服务器运行、支持视频输入的开源模型。选型时要确认模型是否能同时利用画面和音频，以及是否支持后续微调和强化学习。只读取视频帧的模型无法获得语气信息，语音转写也不能完整保留停顿、音量和说话方式。

课程提供了 Emotion-LLaMA 和 R1-Omni 两个参考项目，可以先查看它们的数据格式、推理方法和训练代码，再结合现有设备决定采用哪条路线。

材料建议使用 48GB 显存、Python 3.10+ 和匹配的 CUDA 版本，列出的工具包括 PyTorch、Transformers、PEFT、TRL 和 LLaMA-Factory。具体依赖版本要根据最终选择的模型确定，实际显存占用还受视频长度、采样帧数和训练方式影响。

## 4. 原始模型基线

基线就是模型在本次作业训练之前的表现。先将一段视频输入原始模型，获得情感判断和回应，确认整个推理过程能够运行。之后再对测试集批量推理，保存每条样本的输入编号、预测标签和原始回答。

这部分的作用是提供比较对象。后续微调和强化学习都从同一个选定基座出发，才能判断训练带来了什么变化。

在做基线时就需要确定输出格式和评测方法。三个版本尽量使用相同的视频采样方式、输入信息、提示词和生成设置。运行失败或无法解析的回答也要记录。

## 5. 监督微调（SFT）

监督微调是用“输入和期望回答”的样例继续训练模型，让模型学习这项任务的回答方式。

训练数据需要同时覆盖情感明确和需要进一步确认的情况。情感明确时，回答应包含情感判断及相应回应；信息不足或模态冲突时，回答应说明疑点，并提出相关问题。例如，针对表情和语气不一致的情况，可以询问“你说这句话时，实际是什么感受？”

如果课程数据只有情感标签，就还需要整理回应和追问样例，具体补充方式应与老师确认。字幕、语音转写可以作为输入，包含情感答案的人工解释则不能直接作为测试输入。

微调可以考虑 LoRA 等参数高效训练方式，是否适用取决于模型支持情况。先用少量数据确认训练、保存和重新加载正常，再进行完整训练。训练完成后，保留 SFT 版本并在固定测试集上评测。

## 6. 强化学习（RL）

强化学习阶段在 SFT 模型上继续训练。模型生成回答后，由奖励函数对回答评分，再根据分数更新模型参数。课程要求自行设计奖励函数，这是方法改进的一部分。

奖励可以从以下几个方面设计：

- 情感判断是否正确。
- 是否正确发现模态冲突。
- 信息不足时是否恰当地表达不确定。
- 提出的问题是否有助于进一步判断。
- 是否出现缺乏依据的强断言。
- 信息已经充分时，是否仍然反复回避判断。

这些是初步设计方向，具体分数和权重需要结合标注、验证集结果调整。只奖励“不确定”或“可能”等词，容易让模型对所有输入都套用同一种回答，所以评分需要考虑当前样本是否真的有必要追问。

RL 算法和训练配置要根据模型及显卡确定。完成后保存强化学习版本，再用与前两个版本一致的方法评测。

## 7. 实验评价

课程要求比较原始模型、SFT 模型和强化学习后训练模型，使用以下三个指标。

| 指标 | 含义 |
| --- | --- |
| 情感识别 Macro-F1 | 分别计算每个情感类别的 F1，再取平均，衡量各类别的识别效果，越高越好 |
| 模态冲突识别准确率 | 在有冲突标注的评测数据中，正确判断有无冲突的比例，越高越好 |
| 过度判断率 | 回答中出现无充分依据的确定判断或过度情绪化判断的比例，越低越好 |

材料没有给出后两项指标的完整评分规则，需要确认冲突标签、过度判断的判定标准和统计分母。拒答、非法输出和运行失败也应采用统一处理方式。

三个版本的主要对比应在用户补充回答之前进行。追问之后模型获得了额外信息，可以单独分析判断是否有所改善。

除了指标，还需要分析典型案例，包括识别正确、识别错误、模态冲突和证据不足的情况，说明训练前后的具体变化。如果时间允许，可以再比较不同奖励组合，分析哪些奖励产生了作用。

## 8. Demo

Demo 输入同一段视频，并排展示原始模型与后训练模型的情感判断和回应。

当后训练模型判断不确定时，界面展示它提出的问题，并允许用户输入回答。系统将视频上下文、之前的问题和用户回答一起输入模型，生成更新后的判断。

这里的结果更新通过再次推理完成，不需要在用户回答后重新训练。演示时可以准备情感明确、模态冲突和信息不足的视频，展示不同情况下的表现。
